# Carpeta de Imágenes de Productos

Coloca aquí las imágenes de los productos de la tienda.

## Formato de nombre
- El nombre del archivo debe coincidir con el nombre del producto en minúsculas y sin tildes.
- Reemplaza espacios por guiones bajos (_).
- Formato recomendado: .webp (también acepta .jpg y .png)

## Ejemplos
- Producto "Piqueo Snax" → `piqueo_snax.webp`
- Producto "Aceite Vegetal 1L" → `aceite_vegetal_1l.webp`
- Producto "Inca Kola" → `inca_kola.webp`

## Imagen por defecto
Si un producto no tiene imagen, se mostrará `default.webp`.
